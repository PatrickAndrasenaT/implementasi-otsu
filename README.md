# Segmentasi Gambar dengan Metode Otsu

Implementasi segmentasi gambar menggunakan metode thresholding Otsu untuk memisahkan objek dari latar belakang.

## Requirements

Pastikan Python dan pip sudah terinstal. Instal dependensi dengan perintah:

```bash
pip install -r requirements.txt
```

## Penggunaan

1.  Ubah `image_path` di dalam file `medium.py` untuk menentukan gambar yang akan diproses terserah kamu, tapi pastikan script medium.py dan gambarmu berada di folder yang sama
2.  Jalankan skrip melalui terminal:

```bash
python medium.py
```

Skrip akan menampilkan gambar asli, grayscale, hasil Otsu mentah, dan hasil akhir yang telah dibersihkan, mantap 👍
